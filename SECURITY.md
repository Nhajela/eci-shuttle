# Security

This runs a live service that handles drivers' locations and Telegram accounts. If you find a vulnerability, please
don't open a public issue: use GitHub's "Report a vulnerability" (Security tab) or message
[@HiiNaman](https://t.me/HiiNaman) on Telegram. We'll reply within a couple of days.

Secrets are never in this repo; if you spot one, tell us the same way.
